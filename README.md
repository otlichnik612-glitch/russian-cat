# Russian Cat / Русский Кот

История-курс русского языка с котом Мурзиком и Томом. Уровень A1 начинается в Париже: 7 полных уроков, по 10 новых фраз в каждом. Квартира Мурзика наполняется вещами по мере уроков.

Прогресс хранится в браузере, на этом устройстве. Аккаунт не нужен.

## Что уже есть

- Вступительный экран в парижском саду и знакомство с квартирой
- Уроки 1–7: цели, карточки слов, диалог, грамматика, практика, говорение и повтор
- Озвучка через речь браузера (русский)
- Награда после каждого урока и сцена «Париж завершён» с перелётом в Лондон
- Скачивание урока (документ без ключей) и печатных карточек A4
- Карта курса A1–C1. Следующие города намечены, но их уроки ещё не написаны

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Приложение открывается на порту 8080.

Проверка типов: `npm run typecheck`. Сборка: `npm run build`.
