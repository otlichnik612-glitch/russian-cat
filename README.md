# Russian Cat / Русский Кот

История-курс русского языка с котом Мурзиком и Томом. Уровень A1 — путешествие по городам Европы: в каждом городе 7 уроков по 5–7 минут, в каждом уроке 7 новых фраз.

Прогресс хранится в браузере, на этом устройстве. Аккаунт не нужен.

## Что уже есть

- **Париж — «Первый разговор»**: знакомство, как дела, вежливость, «я не понимаю», откуда ты, да/нет/хочешь, прощание
- **Лондон — «Приезд»**: аэропорт, числа 1–10, транспорт, квартира, погода, телефон, как пройти
- **Мадрид — «Еда и покупки»**: кафе, ресторан, рынок, цены, оплата, вкусно/невкусно, готовим дома
- **Рим — «Люди и семья»**: семья, возраст, внешность, характер, профессии, друзья, семейный ужин
- В каждом уроке: карточки с фразами, диалог (сначала на слух), одно правило и 6–7 заданий — слушание, слова, грамматика, буквы, говорение и повторение прошлых уроков; виды заданий чередуются
- В Париже ученик проходит весь русский алфавит (по 3–5 букв за урок)
- В каждом городе у Мурзика своё жильё, которое он обустраивает за уроки, а любимую вещь увозит с собой
- После 7-го урока — прощание с городом и перелёт в следующий
- Озвучка через речь браузера (русский)
- Скачивание урока (документ без ключей) и печатных карточек A4
- Карта курса A1–C1. Следующие города намечены, но их уроки ещё не написаны

Тексты уроков лежат в `src/lib/course/lessons/` (`early.ts`, `late.ts` — Париж, `london.ts`, `madrid.ts`, `rome.ts`, `berlin.ts`, `amsterdam.ts`, `vienna.ts`, `prague.ts`, `lisbon.ts`, `athens.ts`, `istanbul.ts`, `warsaw.ts`, `budapest.ts`, `edinburgh.ts`). Уровень A1 готов целиком: 14 городов, 98 уроков.

Пока курс пишется, внизу главного экрана есть кнопка «Developer panel» (`src/components/cat/dev.tsx`): переход к любому городу и уроку, показ финала, сброс прогресса. Перед запуском поставить `DEV_TOOLS_VISIBLE = false` — тогда панель открывается только по ссылке с `?dev=1`.
Новые картинки описаны в `docs/grok-image-notes.md`; инструкция для Grok Build — `docs/GROK-INSTRUCTIONS.md`.
Пока картинки не нарисованы, приложение просто их не показывает.

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Приложение открывается на порту 8080.

Проверка типов: `npm run typecheck`. Сборка: `npm run build`.

## Netlify

В настройках сборки:

- команда сборки: `npm run build`
- папка публикации: `dist/client`

Сборка сама кладёт туда страницу и файлы. Не меняйте папку на что-то другое.
